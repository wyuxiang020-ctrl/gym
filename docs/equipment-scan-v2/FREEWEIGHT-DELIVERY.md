# 自由重量与器械教学 · 2026-10-13

[正式入口](https://gym-iota-self.vercel.app/?equipment-scan=1)。本次新增 6 类器械、25 个动作；总计 **14 类器械、34 个动作**。

## 使用方式

1. 拍照扫描，或在“自由重量 / 固定器械”下直接选择。
2. 哑铃、杠铃与龙门架须先选动作，再确认进入教学，不会默认替用户选择动作。
3. 哑铃提供 15 个动作；支持胸部、背部、肩部、手臂、腿臀筛选与名称搜索。长列表可滚动；无结果可以一键清除筛选。
4. 每个动作有匹配的 40–60 秒视频、4 条约 100 字中文说明、3 处橙色加粗易错提醒。动作卡直接说明需要的训练凳、把手、保护架等。
5. 确认后可带入训练记录；仅用户点击添加才保存空动作，不生成重量、次数或完成状态。换器械会清除确认状态，不删除已存训练。

## 识别范围

哑铃可单只或同类成对识别；直杠铃与带导轨的史密斯杆分开分类。龙门架须有清晰滑轮与拉索结构，髋外展须区别于髋内收。壶铃、曲杆、陷阱杆、有氧划船机、45° 倒蹬和无法确认结构的组合机未接入；不推断重量、用户动作或附件可用性。用户仍需对照实物确认器械，并核对所选动作的现场条件。

前后端从同一表生成类别约束，AI 只分类，不返回视频链接或自由生成教程。数据保留原有推胸动作 ID 与交接兼容；跨器械的动作 ID 会拒绝，不会错误带入其他动作。
