# 器械分类选择 · 2026-10-13

第一步由“拍摄器械”改为“器械选择”，默认展示主动选择，拍照识别为同级入口。正式入口保持 https://gym-iota-self.vercel.app/?equipment-scan=1 ，已有书签与桌面快捷方式兼容。

## 交付内容

- 主动选择分为自由器械（4 类）、固定器械（10 类）、绳索与综合（2 类），支持分类、名称/训练部位搜索、无结果清除筛选。
- 自由器械包括哑铃、杠铃、壶铃、EZ 曲杆。哑铃原有 15 个动作保留；新加壶铃 2 个、EZ 曲杆 2 个，当前总计 **16 类器械、38 个动作**。
- 拍照/相册先本地预览，用户点击识别才上传。切换入口保留当前照片；主动选定其他器械后清除旧照片，避免错配。
- 识别中切换主动选择会先确认并取消等待；过期响应不能覆盖新选择。弹窗打开期间识别完成后，再确认切换也会清除原候选。
- 后续步骤返回第一步有确认，清除当前选择，保留已保存的训练记录。重新拍摄按钮直接回到照片入口。
- 网页、训练记录中的嵌入入口、桌面 PWA 快捷方式文案同步为器械选择。
