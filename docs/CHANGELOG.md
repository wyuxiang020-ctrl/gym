## 2026-09-05 — AI 服务从 Anthropic 迁移到 OpenAI

**背景**:旧 Anthropic 链路已能正确加载本地密钥并到达供应商,但持续返回 `403 Request not allowed`;用户确认当前网络地区可用后,决定改用 OpenAI 服务继续联调。

- 移除 Anthropic SDK,改用 OpenAI 官方 SDK和 Responses API,4 个现有接口路径及前端调用方式保持不变
- 统一使用支持文字、图片和 Structured Outputs 的 `gpt-5-mini`;训练与饮食结果使用严格 JSON Schema,并保留服务端与前端双重运行时校验
- 图片识别改用 OpenAI 的 `input_image` data URL 输入;请求设置 `store: false`,避免为单次解析保留响应状态
- 环境变量由 `ANTHROPIC_API_KEY` 改为 `OPENAI_API_KEY`,同时保留 `.env.local` 的 server-only 本地回退加载
- 定位到 Node 直连 `api.openai.com:443` 超时、但本机 `127.0.0.1:7897` 代理可达;增加 `OPENAI_PROXY_URL`/标准代理变量支持,不把本地代理地址写死进源码
- OpenAI 密钥已验证可以访问 `gpt-5-mini`;API 账户充值后,训练解析、饮食解析、按备注重算、图片识别 4 个接口均获得结构正确的真实响应
- 前端把无额度错误转换成明确的中文提示;同步更新架构、错误处理、成本说明和开发规约
