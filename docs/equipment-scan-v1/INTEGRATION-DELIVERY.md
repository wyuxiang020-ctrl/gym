## 体验入口

[从器械扫描开始](http://127.0.0.1:4175/?equipment-scan=1)，也可[直接打开熊猫陪练](http://127.0.0.1:4175/?training-companion=1)。本机服务不在运行时，在 `E:\gym` 执行 `npm run dev:equipment`；该命令只启动/复用服务，不会上传照片或调用模型。地址只对运行服务的本机有效。

1. 选择照片并主动识别，或手动选择坐姿推胸机。
2. 人工核对类别；资料与示范仅在型号匹配时使用。
3. 带入训练记录，点击添加，再选择「用熊猫陪练这个动作」。
4. 开始当前动作，查看记录，按实际填写重量和组数并确认完成。
5. 陪练显示休息计时，准备好后继续；结束时查看当前日期该动作的已保存摘要。

当前仍只支持一类坐姿推胸机。熊猫保留已认可原画和动画；人体动作检测继续暂停。陪练的开始、结束与计时不替用户写训练事实。

## 本轮修复

| 问题 | 修复后行为 | 检查 |
| --- | --- | --- |
| 扫描后打开陪练默认选列表首项，可能是其他动作 | 专用按钮读取实际记录 ID 并进入该动作，原填写入口仍保留 | F01–F04 |
| 已打开另一个动作的陪练时，缺少切换衔接 | 显式进入新动作时结束旧计时，定位、聚焦新的陪练面板 | F04 |
| 卡片显示已添加，但记录随后被删除 | 提示重新添加；重读最新存储后可恢复，不继续使用过期状态 | F06 |
| 保存失败后可能误解为已进入训练 | 失败保留确认内容，不提供陪练交接按钮 | F05、陪练 B03、器械 B11 |
| 截止时间已过但间隔刷新尚未执行时暂停 | 直接进入下一组待准备，不留下暂停的 00:00 | 陪练 B08 |
| 窄屏触控与文字断行 | 陪练按钮、选择框至少 44px 高，关闭按钮不拆行 | 320/390/1100 视口与截图 |
