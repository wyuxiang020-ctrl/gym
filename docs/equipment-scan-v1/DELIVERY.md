## 运行边界

一键启动：在 `E:\gym` 运行 `npm run dev:equipment`。命令检查并复用已运行的本机服务，缺少时启动前端 4175 和器械 API 4177；Ctrl+C 只关闭本次命令创建的子进程。单独启动后端可用 `npm run dev:equipment-api`。前端仍禁止加载环境文件，通过 Vite 代理两个器械端点。后端仅监听 127.0.0.1，启动时读取已有 `.env.local` 到服务端进程（不打印值、不改文件），在授权检查前完成配置加载。限制请求体积、Host 和浏览器 Origin；没有自动上传或启动时模型调用。

API 端点继续可用于项目既有 Vercel 环境，本轮未部署。当前目录的启动器路径相对项目根目录。若服务关闭，页面显示连接失败并保留手动选择；缺少配置时禁用上传，提供重新检查。

专用 `/api/identify-equipment` 已实现，复用现有 OpenAI 图像输入与 strict schema、图像解码/规范化、访问码、限流、日预算、无自动重试与脱敏审计。照片只在当前界面内存预览，不写训练存储；关闭/重置丢弃。不承诺取消等待能停止服务端计费。
