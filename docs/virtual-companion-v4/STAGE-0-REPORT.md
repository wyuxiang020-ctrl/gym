## 留给阶段 1 的技术约束

以下仅是代码核对后的候选方案，不是实施结果或角色设计决定。

- 独立实验入口应在挂载 `AppContent`、要求身体档案前分流，按需加载，不依赖真实训练数据。
- 不复用 `?portfolio-demo=1`：该入口会在开发模式且存储为空时导入合成资料，不适合作为纯角色实验。
- 当前 PWA 会预缓存匹配的 JS；后续需检查按需加载与缓存边界，避免普通入口提前获取角色/姿态大资源。
- `StrictMode` 已启用，后续需验证相机与模型重复初始化、模式切换、跟踪丢失及退出清理。
- 角色需能清楚表达肩、肘和抬手方向；美术风格、拟人程度、物种和性格由下一步共同确定。预设动画、上下文陪练和人体镜像继续分别标识。

阶段 0 的结果允许进入形象讨论；不会自动启动阶段 1。线上可达性、真实手机与摄像头仍分别保持待核/未测。
