2026-10-07。按用户再次提供的[二维卡通参考](user-reference.png)重做当前角色与动作。

## 当前效果

- [本地体验](http://127.0.0.1:4175/?companion-lab=1)，页面标记「手绘功夫熊猫 · V4.3」。服务停止后执行 `npm run dev:companion`。
- [实际动作录像](actual-motion.webm)：待机、招手、抱拳、腾空踢腿与碎步，未开启摄像头。
- [实际姿势截帧](actual-poses.png)：由产品同一个绘制函数与动作数据输出，展示戴帽/摘帽、朝向和动作差异；不是设计稿或导入角色模型。
- 单帧：[待机](idle.png)、[招手](wave.png)、[出脚](kick.png)、[摘帽](no-hat.png)、[像素显示](pixel.png)。

这次改变了显示路线。当前角色采用 **Canvas 2D 轮廓绘制与关节动作**，以描边、侧向口鼻、脸颊、眼斑、眉眼、短爪和橙色斗笠接近参考图的形式。朝左、正面、朝右是预设绘制朝向，不是任意三维旋转；旧三维代码及各版证据保留，但本入口不再加载 Three.js。没有把旧模型再缩放后作为新版，也没有生成一张图片替代可运行角色。

## 动作

| 动作 | 表现 |
| --- | --- |
| 蓄势待发 | 弯爪准备、轻微重心变化、视线移动、眨眼 |
| 俏皮招手 | 探头、较快抬爪和摆爪，表情转为笑容 |
| 抱拳行礼 | 爪子收在胸前，低头致意，再抬下巴 |
| 腾空踢腿 | 压低蓄力、起跳出脚、露出脚掌、落地收势 |
| 灵活小碎步 | 交替抬脚、侧向移动，脑袋和帽檐稍后跟上 |
| 伸个懒腰 | 左/右/双爪伸展、头部响应、闭眼和收回 |

共用 8 秒时间轴，支持循环、暂停、拖动、重启及动作间过渡；表情和帽檐随同暂停。系统减少动态效果偏好关闭默认自动播放。斗笠可以摘戴，清晰/像素共享全部姿势。

镜像模式锁定正面，继续使用原来的本机肩肘映射驱动前爪。切入时清除预设动作，摄像头仍需主动开启。画布故障会冻结动作并停止镜像，重新加载画布后不自动恢复相机或播放。
