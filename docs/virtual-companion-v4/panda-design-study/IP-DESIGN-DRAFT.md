## 角色是什么样的伙伴

建议定位：一个愿意陪你开始、也允许你休息的熊猫搭子。有一点机灵和小得意，做事认真，但不以严厉教练姿态训人。

个性通过行为表现：
- 招呼时先注意到你，再做一个简短回应。
- 等待时安静站稳，偶尔转眼或眨眼，不永远全身弹跳。
- 鼓励时有明确眼神和一个小动作，不每次都大笑欢呼。
- 休息时身体放松，表情舒展；不因用户停下而生气或卖惨。

这是设计提案，不能当作用户已批准的完整人设。角色姓名、具体语气和识别配件在造型确定后再定，不靠堆叠配件增加辨识度。

## 造型优先级

1. 不看五官，纯黑剪影也像同一只角色。
2. 短爪与圆身体仍能表达招呼、准备、走动和休息。
3. 侧面、背面与斜侧保持同样的体积和色块逻辑。
4. 五官能用少量变化表达情绪。
5. 清晰主稿缩小后仍成立，随后才做像素版本。

不继续将旧提示词中的 2.5 至 3 头身、可见肩肘或较长拟人四肢作为硬性美术标准。内部驱动可以有肩肘，外观不必出现人形肩膀或机械关节。

## D 方向的造型草案

![D 短爪灵动](short-paw-direction-d-v1.png)

- 轮廓：紧凑的梨形或豆形身体，头脸略方但边缘柔和，面颊与短口鼻形成侧面层次。
- 比例：从约 2 头身的草图比较起步，最终以站立和动作图同时成立为准；不是把数值交给程序后自动生成成品。
- 黑白关系：奶白脸与腹部，炭黑耳、眼斑与四肢。抬爪和抱爪时，要通过姿态留白和明暗关系区分黑色区域。
- 眼睛：中等偏小，眼白和眼睑服务于视线与表情，避免巨大玻璃球般的婴儿眼。
- 手脚：简化熊掌，放松、张开、收拢的外轮廓有区别。后爪短，仍要画清支撑脚和脚掌朝向。
- 识别点：可从眼斑形状、面颊与前额小毛簇中选一至两个稳定特征。绿色腕结是可移除配件，不是角色唯一识别点。
- 表面：先用清楚的二维主稿、克制色块与阴影描述形体；未来如制作立体版，保留哑光、连续柔软的形态。
- 用户已授权加入草帽和竹子；它们作为可摘取道具，去掉后仍应能认出 D。本体比例与表情继续独立校对。

生成图仅提供造型意向。图上正面仍有少量转头，不能作为精确正交转面；全部视图与动作需要统一设计修订后才可进入资产制作。

## 表情表

至少绘制以下 6 种；同一个头部基准上修改眼睑、眉、嘴和头部倾角，不让脸型在每张图中任意漂移。

| 状态 | 眼与嘴 | 身体配合 |
| --- | --- | --- |
| 平静注意 | 目光有目标，小闭口笑 | 站稳，手爪自然松弛 |
| 好奇 | 视线侧移，一侧眉轻抬 | 小幅歪头，身体稍前倾 |
| 专注 | 眼睑略收，嘴闭合 | 重心稳定，减少装饰动作 |
| 鼓励 | 目光温和，嘴角略升 | 小点头或一只爪短暂抬起 |
| 小得意 | 克制的半笑，轻挑眉 | 下巴略抬，但不挺胸做成人健美姿态 |
| 放松 | 眼睑放松或闭眼，嘴小而舒展 | 坐低或肩背放松 |

避免六张表情只更换嘴型，也避免一直皱眉导致角色看起来在训斥用户。

## 关键姿势表

先画完整身体，再决定如何实现。至少需要自然站立、单爪招呼、准备、抬爪、抱爪、小步、坐下休息、轻庆祝这 8 张。

每张图同时检查：
- 动作意图是否一眼可读；
- 头、胸腹和骨盆的方向是否协调；
- 支撑脚在哪里，脚掌是否真的承重；
- 手爪是否与身体融成一块；
- 黑色剪影是否仍然区分姿势；
- 体积有适度变化时，是否仍像同一只角色。

不强迫所有姿势使用同一个刚性椭圆躯干。可以让腹部压低、背部弯曲、胸腹扭转，但要保持可信的体积感。关节、肩根和腹部应有连续轮廓，不能像几根胶囊插在球体上。

## 动作语言

用户后续要求更大幅、更活泼。D2 的克制动作可保留为常态，D3 增加明显蓄势、起跳、落地、大幅招呼和转体作为表演峰值；下文早期的轻微幅度提案不限制新方向。

动作美感不是“加平滑”一个问题。需要先有清楚的姿势、重心、弧线和轻重，再处理连续过程。

| 项目 | 本角色的目标 | 应避免的结果 |
| --- | --- | --- |
| 重心 | 脚先提供支撑，身体随着意图变化 | 脚不动，整个身体无缘由漂移 |
| 身体弧线 | 头、躯干、爪形成可读的整体方向 | 躯干不变，只旋转手脚 |
| 时间节奏 | 起势、主动作、停顿和收势有区分 | 全程匀速、每个动作一样长 |
| 身体跟随 | 适量先后次序，动作结束能安静下来 | 所有部位同启同停，或永远抖动回弹 |
| 柔软感 | 形状随受力轻微改变，轮廓连续 | 僵硬拼接，或拉伸成橡皮泥 |
| 表情 | 眼神先建立意图，表情与身体一致 | 嘴在笑，身体却像没反应 |
| 小尺寸 | 主要动作幅度与留白在实际尺寸下可读 | 只能放大截图才能看清 |

这套表演规则适用于欢迎、待机和庆祝。真实摄像头镜像应保留用户的方向与时序，不能插入用户没有做过的预备动作、故意延迟或虚构身体运动；滤波只负责减少抖动，并需另测延迟。

## 四条动效稿

下面是设计起点，时间不是已验证指标。应先做短样片，凭实际效果调整。

### 招呼

建议约 1.5 至 2 秒：注意到用户 → 轻微身体倾向与抬爪 → 一到两次小摆爪 → 爪子回落，身体收稳。主要姿势必须独立成立。不是肩部固定频率左右摆动。

### 待机

建议约 4 至 6 秒观察窗：稳定站立为主，少量呼吸、一次目光变化或眨眼即可。不同小动作不全部同步。禁止把全身持续上下跳当作呼吸。

### 鼓励

建议约 1 至 1.5 秒：看向用户 → 小幅点头或抬爪 → 短暂停留 → 恢复安静。应传达“我在陪你”，不演成胜利狂欢。

### 轻庆祝

建议约 1.5 至 2 秒：短暂压低 → 小幅伸展或抬爪 → 满足停顿 → 柔和收势。是否离地需单独比较，不能默认越跳越有活力。

## 像素版本

保留用户对像素风的偏好，但清晰版是造型校对的母稿。

同一角色、同一姿势并排做清晰和像素样图。建议在 64、96、128 像素角色高度做早期可读性对照；这些只是样图探索尺寸，不是技术定案或性能承诺。

重点看眼神、口鼻、爪与身体的空隙、脚底落点。若眼睛合成一块、黑爪消失或轮廓闪动，先改变像素密度与形体设计，不能靠模糊滤镜掩盖。

不因最后显示为像素风就直接放弃身体形变，也不因为考虑三维就牺牲用户喜欢的平面轮廓。
