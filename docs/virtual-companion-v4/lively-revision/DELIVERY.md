# 灵动小熊猫 V4.2

日期：2026-10-07。本次依照用户最新的[卡通参考](user-reference.png)，减少人形肩膀和腿的外观，调整略酷的表情，并丰富角色动作。当前为实际三维程序运行结果，尚未部署。

## 体验与实际画面

- [打开本地新版](http://127.0.0.1:4175/?companion-lab=1)，页面标记「灵动小熊猫 · V4.2」。服务停止后在项目目录执行 `npm run dev:companion`。
- [实际动作录像](actual-motion.webm)：依次展示待机、挥爪、抱爪、蹦跳和左右晃动；隔离浏览器录制，未开启摄像头。
- 实际截图：[待机](idle.png)、[挥爪](wave.png)、[抱爪](fold.png)、[蹦跳](hop.png)、[像素挥爪](wave-pixel.png)。

圆豆形躯干直接连接短前爪，后爪没有独立的人形腿段。耳朵缩小，脸部采用略不对称的眉眼、暖色鼻子和得意的嘴角；挥爪与蹦跳会切换笑容。头脸、肚皮与爪子仍由同一个可运动的三维角色呈现。

| 动作 | 动态细节 |
| --- | --- |
| 悠闲待机 | 轻轻呼吸、眨眼、歪头和重心移动 |
| 挥爪招呼 | 先准备再抬爪，小幅摆爪并带动身体 |
| 得意抱爪 | 双爪抱在肚前，转身、抬下巴 |
| 蓄力蹦跳 | 预备压缩、起跳伸展、露出足底、落地回弹 |
| 左右晃晃 | 交替抬小脚、左右移动，头部反向响应 |
| 伸个懒腰 | 可选画面左爪、右爪或双爪，配合头部和身体 |

动作可循环、暂停、重启或拖动时间；切换动作有 350 毫秒过渡，暂停也会冻结过渡。默认自动播放轻微待机，系统选择减少动态效果时则保持暂停。清晰和像素模式共享完整姿势。

镜像模式继续只映射原有肩肘输入，内部关节驱动短爪；切入镜像会清除上述预设表演。自动蹦跳、眨眼等不冒充真实人体跟随。本次没有修改姿态模型、权限流程或训练记录。
