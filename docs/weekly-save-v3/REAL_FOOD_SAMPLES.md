# Gym 真实餐食照片评测准备

当前真实照片样本、称重与可追溯营养参考尚未收到，因此本轮真实照片效果为 NOT_MEASURED。历史合成照片仅是软件与模型回归素材，不能充当本次真值。

## 需要用户提供的材料

建议 6 份独立餐食：2 份单一食物或有包装标签的食物、2 份多食材组合、1 份含油酱汁的餐食、1 份存在遮挡的餐食。样本少，按个案报告，不声称覆盖所有饮食。

每份提供：原始照片及使用授权；每种食物名称、可食部分称重克数、生/熟状态、烹调方式、容器去皮方式；油/酱汁称重与剩余情况；营养参考的 URL/出版物条目/包装营养表照片，版本或访问日期，以及对应每 100g 的 kcal、蛋白质、碳水、脂肪。可加一张称重读数照片。不要包含人脸、住址、医疗资料等无关内容；未获准公开的照片不入演示。

用样本编号，不用参与者实名。原图与称重、营养来源形成一一对应清单，保存文件哈希。混合菜如果无法核实可食重量或烹饪损失，就标记参考不充分，不能补造精确真值。

## 四层分别评估

| 层次 | 对照依据 | 记录方法 |
|---|---|---|
| 识别 | 人工核对的食物清单 | 逐项正确/遗漏/多识别；别名判定提前记录 |
| 份量 | 独立称重，可食部分，状态一致 | 原始预测与称重的克数差、绝对误差及相对误差；0 分母不算百分比 |
| 人工修正 | 用户实际输入的更正内容 | 每次修改、耗时、被意外改动的无关项；修正前后都留档 |
| 营养汇总与保存 | 称重 × 可追溯参考值，及已确认编辑值 | kcal/P/C/F 各自误差；程序汇总是否等于条目之和；保存与重开是否一致 |

区分“相对参考营养估计的误差”和“实验室测得真实营养成分”：这里通常只有前者。看不见的油不能靠模型估算定义成真值。若参考值不匹配生熟状态或品牌，应先标记不可比较。

第一遍只给照片，保存模型原始响应；第二遍由你输入称重和参考修正，保存修正过程与确认内容；第三步刷新重开并导出，核对持久化与汇总。不为提高分数重新选最佳一次。每次请求，包括失败，记录状态、耗时、重试关系、usage 和估算成本；自动重试关闭。
