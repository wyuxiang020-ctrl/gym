# Gym V3.2 保存与教学资料验收口径

2026-10-01。适用于明确确认缺失重量的保存流程，以及唯一附加的教学网页收藏路径。旧 20 条仍为历史回归集，V3 的冻结留出仍是当时证据；本轮不重跑或重评分旧模型结果，没有新的独立模型测试集。

## 保存语义

1. unknown/null 未经用户确认仍不可作为已完成 AI 记录保存；禁止 0、历史重量或模型替用户补确认。
2. unknown/null 且 `missingWeightConfirmed === true` 允许保存，但仍需 `done === true`，以及有效且互斥的次数/秒数。确认缺失不是确认未来计划已完成。
3. 已确认缺失可用于完成事实与训练型打卡资格，不计入 kg·次容量或现有 MET 热量估算。界面必须显示汇总不完整，不能把未估算解释为消耗为零。
4. API 输出不接受用户确认权；前端模型解析丢弃确认字段，本地草稿/备份校验并保存合法确认。旧 0/unknown 不得自动升级。
5. 取消数值编辑保留原状态；改为明确重量清除缺失确认；新加组不复制确认/完成；批量改重量清确认，撤销恢复原快照。
6. 核对最终本地存储、刷新重开和导入导出，不仅核对 JSON 格式。网络及存储失败保留已确认草稿或旧值，手动重试后值一致。

## 教学资料

复用现有动作详情和字符串存储。普通 HTTP/HTTPS 网页只在用户点击时新标签打开，无 iframe/预取；拒绝脚本、data、file、凭证及非法 URL。直链视频保持可用控件并提供失败回退，不宣称所有网站/视频可达或可播。保存/删除失败保留原值，当前弹层内编辑草稿可继续重试；关闭弹层未保存的链接不承诺恢复。

## 证据分类

- 自动化纯逻辑与固定响应浏览器回放分别列项，样例全为合成。耗时是脚本耗时，不是用户完成时间。
- 首次不满足、新实现中间结果和最终结果分别保留，不替换历史失败。新增断言首次运行在冻结的实际源码上，而非重新手写旧逻辑。
- 本轮实际模型调用 0，模型成本 0；非模型基础设施成本未计。未测模型正确率、真实食品识别误差、用户满意度或主动复用。
- 用户对本人及朋友的使用反馈属于转述的定性线索，不当作正式真人测试。保留既有真人脚本及未测状态，不要求招募后才能做软件验证。
- 不把同一组脚本在两个视口执行、录屏重跑或故障恢复重试当作新独立用户/模型样本。
