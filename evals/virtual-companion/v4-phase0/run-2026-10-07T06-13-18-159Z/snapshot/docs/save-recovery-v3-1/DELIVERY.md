## 本轮目标范围与完成标准

目标：保证训练记录从输入、编辑确认到保存、重新打开的一致性，已有数据不因尚未确认的编辑而改变，失败后保留仍可用的输入和预览。

范围：先核对 V3 已完成内容，复现阻断核心任务的反例；只修复重量确认前写入和未完成草稿刷新丢失。增加取消重量编辑，不新增账号、社交、Agent、成长或新的饮食模块，不调 Prompt 或更换模型。

完成标准及结果：

1. 保留修改前失败，原场景修改后通过：完成，三个首次失败均保留。
2. 最终存储与确认内容一致，重开不变；网络/存储失败可恢复：完成，固定响应流程和一次真实模型联调分别验证。
3. 历史回归保留、新结果另开版本，分类记录失败、耗时与可得成本：完成；没有重跑历史 20 题来替换旧成绩。
4. 可展示正常与失败恢复流程，版本和验证性质明确：完成，三份完整录屏及受保护 Preview。
5. 不伪造真人、作者自测、营养参考或效果指标，明确发布状态：完成。达到这些标准后停止扩展。

## 剩余限制与停止条件

1. 本轮没有真人任务或作者亲自自测，真实效率、满意度、学习成本均未知；软件测试通过不等于用户一定能正确核对。
2. 模型仍会错，单次成功只证明当前链路可用，不证明总体准确率、稳定 SLA 或所有输入正确。历史 20 题用于回归，V3 的 8 条作者留出仍是当时记录，本轮没有新独立模型质量结论。
3. 匿名访问新版仍受限，完整线上浏览器直接调用的作者自测未完成；真实联调通过认证工具转发。生产未更新。若之后决定对外开放，需要单独确认发布及访问方式，不在本轮解除保护。
4. 草稿仅当前标签页；未确认重量输入不持久化，刷新回到原已确认值。手动已保存动作增删组会关闭该动作未确认的重量编辑。结构严重损坏的草稿不保证全量恢复，只做保留与提示。
5. localStorage 不是云备份，清缓存、跨设备、跨标签页并发和长期使用仍有边界。旧正数来源无法全面追溯，旧 0 的保守兼容策略不变。
6. 只验证 Edge 桌面与 390px 视口，不等于真机 Safari 或触屏验收。无真实饮食真值，营养和 MET 消耗仍是估算。

本轮标准已达到，停止扩展；不为填满一周新增模块，不把招募作为放行条件。代码仍在工作区，Preview 已发布，Production 未发布。
