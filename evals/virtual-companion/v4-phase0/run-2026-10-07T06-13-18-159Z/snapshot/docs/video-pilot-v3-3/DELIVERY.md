# Gym 训练示范 V3.3 交付报告

2026-10-01。本轮把现有训练中的动作示范与记录连接起来：用户主动加载官方真人视频，在当前动作页观看，关闭后继续填写并保存。范围仅为既有「全身训练 · 新手三日」的 Day 1 四个动作，不修改训练处方，也不扩展饮食、账号、社交或 AI 教练。

当前为本地可演示版本，尚未部署 Preview 或 Production。四段外部视频已在当前电脑的隔离 Edge 浏览器内观察到实际播放和时间推进；这不是全片审校、真机兼容性或真人任务验证。未购买视频服务、接受新付费条款、读取密钥或上传健康记录。

## 本轮目标和完成边界

用户澄清原始目标是训练时少切换软件，而非单纯练后补录。V3.2 已解决缺失重量确认、保存恢复与普通网页收藏，本轮不重复实现。既有模板 Day 1 只有四个动作，因此以完整训练日作为最小切片，不为凑 6 至 8 项而改训练内容。

完成标准：预选来源与动作变式对应；主动点击后原页观看；视频失败可取消、重试、打开来源或返回；看视频不修改训练事实或重量；返回编辑确认、保存、刷新重开后的数据一致。首次失败和重试均保留，测试不使用用户真实浏览器档案。

本轮冻结 [80 个源码及配置文件、676 个既有文档与评测文件哈希](../../evals/video-pilot/v3-3/baseline.json)，并保存源文件快照。工作区在本轮前已经有大量未提交修改；这些修改全部保留，不按 Git HEAD 把历史工作误算为本轮新增。未 commit、push 或部署。

## 实际改动

| 场景 | 本轮前 | 本轮后 |
| --- | --- | --- |
| 查看当前动作 | 静态提示或用户自行收藏的网页/直链 | 四个试点动作预选官方真人视频，放在详情顶部 |
| 进入入口 | 记录中的动作要领按钮 | 有试点视频的动作显示「视频与要领」，其余继续原入口 |
| 名称不明确 | 精确静态详情匹配 | 视频也保守精确匹配；「卧推」「划船」、其他器械或变式不自动套用 |
| 未点击观看 | 没有内置外部播放器 | 不加载 YouTube 脚本、播放器或缩略图，点击后才连接 |
| 等待和失败 | 收藏直链有失败回退 | 官方播放器初始化总等待和连续缓冲分别最多 15 秒；取消、销毁、手动重试，显示来源平台错误 |
| 返回训练 | 外部网页需切换标签 | 关闭当前详情即可继续；记录入口返回记录，动作库入口返回原页面 |
| 数据兼容 | exerciseVideos 是用户收藏字符串 | 保持原数据结构，内置元数据独立存在，不覆盖收藏、不迁移训练数据 |

产品代码新增 `teachingVideos.ts`、`TeachingVideoPlayer.tsx`；修改 `ExerciseDetailSheet.tsx`、`StrengthLogger.tsx`、`WorkoutSection.tsx` 和 App 版本标签。store、类型、训练模板、API、模型、预算保护及 PWA 缓存策略与本轮基线一致。

播放器保留原平台控件与标识，使用隐私增强域名和页面 origin；不自动播放，不下载、离线缓存、剪辑或重新托管视频。隐私增强不等于没有数据传输；观看会连接第三方。既有页面还使用 Google Fonts，不能宣称整个页面零外联。

## 如何打开与演示

本地地址：http://127.0.0.1:4174/ 。版本标签为「训练示范 V3.3」。原 4173 端口已有进程，本轮未终止它，另外使用 4174。端口和域名不同的浏览器存储相互独立，看到空档案不表示旧数据被删除。不要清除原浏览器数据。

正常路径：建立或导入自己的档案 → 训练 → 训练计划 → 全身训练 · 新手三日 → 训练记录 → Day 1 · 全身 A → 某动作的「视频与要领」→「加载真人示范」→ 点击原站播放按钮 → 返回当前记录 → 确认重量和实际完成情况 → 刷新重开核对。已有活跃计划时，须自行决定是否切换，产品不自动替换原计划。

失败路径：视频加载或缓冲超时、发布者禁止嵌入或网络出错 → 明确错误 → 手动重试，或打开原来源，或返回记录。取消、失败及播放都不写入重量和完成状态；源视频无法观看时，文字提示和用户原收藏继续可用。返回静态资料不是声称视频需求已经被满足。

本地当前启动的是前端开发服务，手动模板/记录/视频可演示；它不单独提供真实 AI 后端。本轮没有为测试调用 AI，也未改变既有后端保护。

本目录提供正常与失败恢复的录屏索引，录屏使用合成记录和明确标注的播放器事件回放，不是真人操作或实际媒体播放。真实媒体以单独的原生播放状态、时间推进与截图证明，不混入回放统计。

## 真人测试待办与剩余限制

原[真人任务脚本](../weekly-save-v3/HUMAN_TASKS.md)保留未测。本轮可追加下列观察任务，但招募不是后续软件工作的前置条件：

1. 参与者使用自己适合且熟悉的训练安排，不要求为测试尝试陌生负重。选一个需要复习的动作，观察能否找到对应示范。
2. 记录是否离开 Gym 查资料，以及缺少内容、变式不符、网络失败或看不懂的具体原因。主动拓展学习与被迫外搜分开。
3. 记录打开示范、理解后继续、编辑确认与保存的总耗时、编辑次数、求助情况和漏改错误；最终存储与参与者确认逐项核对。
4. 另一次自然训练机会观察是否主动再打开，不以要求使用后的完成情况替代留存。作者自测单独标记，不能冒充独立参与者。

目前未测中国大陆网络、健身房弱网、iPhone/Safari 真机及跨设备；只有当前电脑 Edge 的两种窗口宽度。外部视频可能下架、要求登录、出现广告、变更嵌入权限或不可用，字幕也不保证中文。没有本地离线视频，不能为了绕开来源限制下载重托管。

仅覆盖四动作，没有全库覆盖、模糊别名推断、自动动作纠正或专业机构认证。旧静态说明和现有模板没有新增专业审校。弹层既有键盘焦点管理仍待完善，不能宣称已完成全套无障碍验收。本地存储不是云备份；本轮不建立账号或同步。

饮食选择场景本轮未实施。先停止扩展这条已完成的最小训练流程；后续再决定适合的授权视频库、公开发布，以及一个明确的餐食选择任务，不把这些未做工作写成已完成。

## 可同步到作品集的准确表述

我根据作者关于训练时仍需外部查视频的反馈，识别了记录工具与现场教学任务之间的缺口。在保留既有数据与预算保护的基础上，为一套现有训练日整合四个可追溯的官方真人示范，设计主动加载、限时等待、取消重试及返回记录流程。通过固定播放器事件、故障注入和最终存储检查验证软件行为，并另外验证四段视频在当前网络实际开始播放。版本目前仅在本地，尚无真人任务效率、满意度或留存提升的证据，也不声称替代教练或完成一站式产品的全部目标。
